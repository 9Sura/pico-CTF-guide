# The Symbol of the Hacker:

The shell is dangerous!

* Deleting files is permanent
* Any file can be accessed at any moment in the shell

# Got Shell?

SHELL DEFAULT EX: Q0h313th@pico-2019-shell1:~$

## 1. What does "Q0h313th" mean?
- User named "Q0h313th" is logged into the shell

## 2. What does pico-2019-shell1 mean?
- The shell is on a computer called "pico-2019-shell1"

## 3. What does ~ mean?
- The shell is pared in Q0h313th's home directory '~'
  - Full path for '~' expands to '/home/Q0h313th'

## 4. What does $ mean?
- '$' is a separator
  - Everything before is computer generated prompt
  - Everything after is the user typed command
